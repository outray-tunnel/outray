This page is retained for existing links. The main installation guide is at [Install the CLI](/docs/installation).

Use Node.js 18 or later for the complete authentication workflow:

~~~bash
npm install -g outray
outray --version
outray login
~~~

Start your application separately, then expose its port:

~~~bash
outray 3000
~~~

Keep the application and CLI running for as long as you need the public URL. Continue with [Opening a tunnel](/docs/opening-a-tunnel), or see the [CLI reference](/docs/cli-reference).
