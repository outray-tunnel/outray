Tunnels, Observability, Secrets, and Uptime use the selected organization as their workspace boundary. Human membership controls dashboard access; scoped API tokens authenticate machine clients.

Resources do not move between organizations when you switch the dashboard selection. Likewise, choosing an organization or vault in a CLI configuration file does not grant access: the authenticated identity or token must be authorized for that target.

Use the dashboard's current controls for any account-specific availability or limits. These guides describe implemented workflows, not billing entitlements or a guaranteed AI allowance.
